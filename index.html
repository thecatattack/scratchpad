FRC #451 Cat Attack • GitHub Pages Build Required

Your browser opened the unbuilt source file instead of the compiled web app. Turn on the automatic GitHub Pages builder once to fix this permanently:

  1. Open your repository on GitHub and click Settings.
  2. In the left menu, click Pages.
  3. Under Build and deployment → Source, change it to GitHub Actions.

Wait about 1 minute for the workflow to finish, then refresh your GitHub Pages link.
